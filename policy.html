Privacy Policy

Last updated: [10/31/2026]

Short version

This site doesn't collect anything. Your code never leaves your browser.

How obfuscation works here

When you paste code or upload a file and click Obfuscate, the work happens in your browser — either in a background Worker or on the main thread if a Worker isn't available. Your script is never sent to a server, logged, or stored anywhere by this site.

What this site does not do

  • No account, no sign-in
  • No cookies
  • No analytics or trackers
  • No server-side storage of your code or its output

Hosting

If this page is hosted on GitHub Pages or a similar static host, that host may log basic technical data (like IP address and request time) under its own privacy policy, separate from this one. This site adds nothing on top of that.

Changes

If this policy changes, the date at the top will be updated.
